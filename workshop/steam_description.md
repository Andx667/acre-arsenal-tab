# ACRE Arsenal Tab

**ACRE Arsenal Tab** (AAT) adds a dedicated "ACRE items" tab to the ACE Arsenal's right-side panel, listing every ACRE antenna and radio — including radios with unique IDs — in one place.

# Requirements

- [CBA_A3](https://steamcommunity.com/sharedfiles/filedetails/?id=450814997)
- [ACE3](https://steamcommunity.com/sharedfiles/filedetails/?id=463939057)
- [ACRE2](https://steamcommunity.com/sharedfiles/filedetails/?id=751965892)

# Features

- **ACRE items panel** — a dedicated right-panel button in the ACE Arsenal, next to ACE's own categories
- **Full radio coverage** — lists every ACRE antenna and radio, including radios with unique IDs
