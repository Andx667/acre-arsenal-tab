__Requires__ [CBA_A3](https://github.com/CBATeam/CBA_A3), [ACE3](https://github.com/acemod/ACE3), and [ACRE2](https://github.com/IDI-Systems/ACRE2).

__ACRE Arsenal Tab__ (AAT) adds a dedicated "ACRE items" tab to the ACE Arsenal's right-side panel, listing every ACRE antenna and radio — including radios with unique IDs — in one place.

The project is entirely __open-source__ and any contributions are welcome.

Steam Workshop: <https://steamcommunity.com/sharedfiles/filedetails/?id=3770085262>  
Discord: <https://discord.gg/ag4v6kxYAa>

## Features

- Adds an "ACRE items" right-panel button to the ACE Arsenal
- Lists all ACRE antennas and radios, including radios with unique IDs
